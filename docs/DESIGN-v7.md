# DESIGN v7 · DARK DATA CONSOLE（深色数据台）

> 日期：2026-11-02 ｜ 触发：v6 UI 被否（「ui太丑了」）｜ 范围：整站，不是只改新三页
> 设计稿：`docs/design/v7-home.png`、`v7-health.png`、`v7-evalset.png`、`v7-report.png`
> 实现：`src/v7.css`（最后叠加层）｜ 默认主题：dark

---

## 1. 为什么重做

v5/v6 的「纸感 + 纯黑 + 直角 + 密集小字」像印刷品或后台报告，不像现代产品：

- 大面积米黄 + 纯黑标题，视觉重量太硬；
- 直角、发丝线、密集小字，页面显得旧、挤、没有呼吸；
- 新三页（健康/评测/报告）信息密度过高，卡片没有层次；
- 朱红只承担动作，整体缺少现代产品的色彩层次。

v7 换的是**视觉语言**，不是信息架构：

| 维度 | v5/v6 | v7 |
|---|---|---|
| 底色 | 纸感米黄 `#f2efe7` | 深石墨 `#070b12` + 青/紫环境光 |
| 卡片 | 直角 + 发丝线 | 12–16px 圆角 + 玻璃底 + 柔和阴影 |
| 主色 | 朱红 `#b23a17` | 青色 `#22d3ee` + 紫色 `#a78bfa` |
| 数字 | 衬线 | 现代无衬线 + 800 字重 |
| 导航 | 等宽小字 | 圆角胶囊 + 青色激活态 |
| 气质 | 编辑部手册 | 数据产品 / 控制台 |

信息架构、文案、数据、路由、23 组验收全部不变。

## 2. 设计令牌

### 深色（默认）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#070b12` | 页面底 |
| `--bg2` | `#0c1220` | 次级底 |
| `--panel` | `rgba(17,24,39,.64)` | 玻璃面板 |
| `--panel2` | `rgba(30,41,59,.52)` | 次级面板 |
| `--ink` | `#f3f7ff` | 标题/数字 |
| `--text` | `#d6e0ef` | 正文 |
| `--dim` | `#9aabc2` | 次级文字 |
| `--dim2` | `#8494ab` | 标签/注释 |
| `--act` | `#22d3ee` | 主操作/强调 |
| `--violet` | `#a78bfa` | 渐变辅助 |
| `--judge` | `#fbbf24` | 警告 |
| `--risk` | `#fb7185` | 风险 |
| `--ok` | `#34d399` | 通过 |
| 圆角 | 8 / 12 / 14 / 18 | 控件 / 卡片 / 面板 / 大容器 |

### 浅色（备用）

浅色不是纸感，而是「白天控制台」：`#eef2f8` 底、白卡、深青主色 `#155e75`、深琥珀/深玫红/深绿语义色。两套主题都通过对比度审计（0 违规）。

### 字体

- 正文/标题：`Inter, Segoe UI, PingFang SC, ...`
- 标签/代码：`ui-monospace, SFMono-Regular, ...`
- v5 的衬线数字全部改为无衬线 800 字重，避免「报纸感」。

### 背景光

```
radial-gradient(1100px 620px at 12% -12%, rgba(34,211,238,.14), transparent 62%),
radial-gradient(900px 520px at 92% -8%, rgba(167,139,250,.12), transparent 62%),
44px 网格
```

只在页面顶部 760px 内可见，向下淡出，避免整页发光。

## 4. 响应式

- 1000px：模块卡 2 列、健康卡 2×2、Hero 间距收紧。
- 720px：模块卡单列、健康卡单列、报告纸内边距 24/18px、Hero 标题 34–44px。
- 三档视口（1440 / 820 / 390）无横向溢出，验收通过。

---

## 5. 可访问性

- 深色：0 违规；浅色：0 违规（35 视图 × 双主题）。
- 所有状态同时有文字（失败/将过期/已标注），不只靠颜色。
- 焦点环改为青色 2px + 3px offset。
- 打印：白底黑字、隐藏导航、A4 约 2 页。

---

## 6. 实现

- `src/v7.css` 是最后叠加层，构建顺序：`styles → v4 → v4-responsive → v5 → v6 → v7`。
- `src/index.html` 默认主题改为 `dark`；用户手动切浅色仍保留。
- 不修改任何 `data/*.json`、路由、信息架构或验收断言。
- 截图：`node scripts/_shot-v7.js` 生成四张评审图；`node scripts/shots.js` 生成全站基线。

---

## 7. 已知取舍

- v7 是「整站换肤」，底层仍有 v1–v6 的 DOM 结构；少数 v5 硬编码颜色用 `!important` 覆盖，后续若继续迭代，建议把组件样式逐步收敛到 v7。
- 浅色主题保留但不再是主视觉；如果确定只用深色，可在下一轮移除切换按钮与浅色令牌，减少维护面。
- 评测集 30 卡仍是长页面；如果觉得太长，下一轮可加「默认 12 条 + 显示全部」的分页。
