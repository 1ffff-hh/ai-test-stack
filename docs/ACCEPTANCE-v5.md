## 3. 这一轮抓出并修掉的真实问题（14 个）

按严重程度排：

1. **诊断报告方案名几乎不可见**。`.drn` 继承了墨底 `.diag` 的浅色令牌，在纸卡上是「白字白底」。
   修复：报告卡内所有文字显式回墨色；并把「报告态」加入对比度审计（之前只审初始问题态）。
2. **报告底部按钮被卡片裁切**。`.drActs` 高 30px，按钮 38px，溢出到卡片外。
   修复：容器与按钮统一 34px；`clientHeight === scrollHeight`。
3. **角色卡进度条横穿整页**。`<i>` 绝对定位没有 `position:relative` 祖先，7 条红线从卡片一直画到页面右侧。
   修复：重排角色卡网格 + `position:relative`；进度条只在卡内。
4. **组合卡残留 v3 圆角/彩色边框/渐变分数**。与 v5 语言冲突。
   修复：`#bGrid .bcard` 直角发丝线；分数改衬线墨色；去掉 `::before` 光斑。
5. **总览页统计写死 11 款工具 / 12 个套餐**。数据扩到 29/57 后页面还在说旧数。
   修复：改为从数据读取（`data-c` 标记 + renderOverview 填充）。
6. **820px 顶栏横向溢出 6px**。`.topbar` 的 `margin:-28px` 与 `.shell` 的 22px padding 不匹配。
   修复：在 1000/700 断点分别对齐 margin 与 padding。
7. **390px 子导航左侧被裁切、筛选按钮压成单字竖排**。面包屑 + 7 个类型 tab 挤在一行。
   修复：移动端隐藏面包屑、sibnav 横向滚动；segGroup 允许换行、seg 不收缩。
8. **套餐表 10 列横向溢出**，用户看不到「超限/风险/选它」。
   修复：收成 8 列，模型与工具折进单元格；默认显示前 20 档 + 「显示全部」；窄屏才横向滚动。
9. **自动新闻第一版抓进 120 条，含标题党与 HTML 实体重复**（`Zest&#8217;s` 与 `Zest’s` 并存）。
   修复：标题必须命中强关键词、标题党词过滤、HTML 实体解码、按规范化标题去重；历史条目也重新过筛。
10. **审计与验收失败仍返回 exit 0**。CI 里「跑过了」但不会红。
    修复：`process.exitCode = 1`。
11. **审计只覆盖默认问题态，漏掉报告卡**。报告卡是另一套配色，第一版就漏了白字白底。
    修复：审计额外答完三问，审一次 `home-report`。
12. **emoji 图标与「数据可信」定位冲突**（🇨🇳 / 🛠️ / 🧩 / 🔮…）。
    修复：全部换单色字形；顶栏图标改内联 SVG。
13. **热力图 29 列没有横滚提示**，首列滑走后不知道在看哪项能力。
    修复：首列 sticky + 底部横滚提示。
14. **工具卡显示「29 / 29 款工具」**，全量时是废话。
    修复：全量时只显示「29 款工具」。

## 5. 自动更新验收

最近一次真实运行（2026-11-01，联网，130.8s）：

| 项 | 结果 |
|---|---|
| 新闻源 | 9 / 12 成功；3 个失败（Anthropic 403、Google AI 404、HuggingFace timeout） |
| 价格页 | 8 / 14 成功；1 个页面指纹变化（Anthropic Pricing）→ 页面标「有变化，去核价」，不改价 |
| 新增条目 | 7 条；去重后自动库 31 条 |
| 新鲜度 | 工具 1 天 / 套餐 1 天 / 优惠 3 天 / 免费额度 1 天 / 新闻 1 天 / 角色 1 天 / 冲击 1 天 |
| 写盘范围 | 只写 `news-auto.json` / `_price-snapshots.json` / `_refresh-report.json` |

失败源没有被隐藏：`data/_refresh-report.json` 里保留 `err`，页面「数据源」逐条显示。这是刻意设计——**一个不敢显示失败的数据站，不值得信**。

## 6. 已知限制（没藏）

1. **自动新闻没有人工判断**。只保证来源与时间；默认不显示，需手动打开「含自动抓取」。标题过滤只能挡明显标题党，挡不住「相关但没用」。
2. **价格页成功率 8/14**。SPA、反爬、地区限制都会导致失败；报价制产品（testRigor / mabl）仍是第三方区间，不是标价。
3. **没有薪资数据**。没有可靠公开源；角色页只写职责、证据与风险，不写钱。
4. **角色渗透度 / 替代度是编辑判断**。页面标了「本站判断」，依据写在卡片里；不能当调研数据引用。
5. **汇率固定 7.25**。只用于同表比较；真实支付价随汇率、税费、地区变化。
6. **审计只测颜色对比度**，不覆盖屏幕阅读器语义、动效可访问性；键盘路径由 verify 单独覆盖。
7. **视觉基线没有像素 diff**。`docs/shots` 是人工比对基线，不是 CI 卡点。
