# PRODUCT v5 · 从「选型站」扩成测试人的判断台

> 日期：2026-11-01 ｜ 版本：2.0.0 ｜ 数据核验日：2026-11-01
> 这份文档记录五条需求背后的产品判断、查到的外部依据、以及明确的非目标。
> 所有价格与事实都能在站内「数据源」或本文末尾的来源清单里回溯。

---

## 0. 一句话结论

这五条需求不是「加五个页面」，而是把产品的问题域从 **「买什么」** 扩到 **「我在哪、行业在变什么、我该怎么应对」**。
能做，而且比原来更有留存——因为「工具价格」是低频需求，「职业位置」是高频焦虑。

但有三条硬约束必须认：

1. **数据维护成本是天花板**。工具从 11 到 29、套餐从 12 到 57，人工核价的工作量翻了 4 倍。所以这一轮把「自动更新」做成基础设施，而不是事后补脚本；并且**价格只告警、不自动改**。
2. **可信度比覆盖量重要**。自动抓的新闻如果混进人工列表，一次标题党就能毁掉整页。所以自动条目单独文件、单独标记、默认不显示。
3. **判断要能被反驳**。角色渗透度、活动替代度都是编辑判断，不是调研数据；页面上必须写「本站判断」并给出判断依据，否则就是另一种形式的贩卖焦虑。

### 1.3 同行的产品形态：缺什么

- **清单站**（awesome-* / GitHub 榜单）覆盖全，但不回答「这套组合多少钱、能不能进 CI」。
- **评测站**（AI 工具榜）排名常带赞助位，且对国内支付/网络/数据条款零覆盖。
- **测试平台官网**（testRigor / mabl）只讲能力，不讲「报价制到底怎么算」。
- **职业内容**（公众号/视频）讲焦虑多、给证据少；讲「学什么」多、给「可验证的产出」少。

本站的空位：**把「工具价格」「岗位位置」「行业变化」放在同一套证据标准下**——每条有来源，每个判断有边界。

## 2. 五条需求 → 产品决策

### 需求 1：更新所有数据（后期自动更新）

**做了什么**

- 工具 11 → 29：编程外壳 23（国内 11 / 国际 12）+ AI 测试平台 6（Playwright / testRigor / mabl / QA Wolf / Katalon / Applitools）。
- 套餐 12 → 57：国内 24 / 国际 33；每一档都有 `currency`、`priceLocal`、`price`（人民币等值）、`restrictions[]`、`verified`。
- 免费额度 34 条（`freebies.json`）：云厂商新户 / 模型免费层 / Agent 免费档 / 学生创业四类；每条必须有 `trap`；过期活动保留并标「已过期」。
- 自动更新：`scripts/refresh.js` 抓 12 个 RSS + 14 个价格页；`.github/workflows/data-refresh.yml` 每周一跑。

**关键决策**

- `price` 永远存人民币等值，另存 `priceLocal` + `currency`。原因：「我的组合」求和逻辑不能改；用户又要看到 `$20`。
- `restrictions[]` 单独成字段，不塞进 `risk` 一句话。原因：国际套餐的失败点通常是「支付/网络/数据条款」，不是价格。
- 自动更新**只写** `news-auto.json` / `_price-snapshots.json` / `_refresh-report.json`，不碰人工核过的 `tools/plans/promos/news`。原因：一次自动改错价，比不更新更伤信任。

### 需求 1.3：白嫖

**做了什么**：34 条，每条四段：怎么领 / 上限 / 坑 / 过期。含 3 条反面案例：

- Cerebras 已取消永久免费，只剩 $5/30 天；
- HuggingFace「免费」实际约 $0.10/月；
- Muse Code 明确没有免费档。

**关键决策**：不删除过期条目。腾讯混元 Hy3 限免 10-31 到期，保留并标红——「免费额度会消失」这件事本身就是产品信息。

### 需求 2：AI 大事模块

**做了什么**：32 条人工 + 31 条自动；六类（模型/产品/价格/政策/资本/安全）；国内/国外双线；每条人工条目必须写「对测试的影响」；自动条目默认不显示。

**关键决策**

- 人工与自动**分文件**，页面分开标记。原因：自动抓取无法保证 relevance，混在一起会稀释可信度。
- 自动抓取加了标题党过滤（紧急/叫停/重磅/刚刚…）与「标题必须命中强关键词」。原因：第一版抓进来 120 条，一半是「XX 获奖名单」。
- 价格页只做指纹告警，不自动改价。原因：自动解析会把「$20 起」读成「$20」。

### 需求 3：AI 对测试的冲击

**做了什么**：8 组数据、5 个变化、9 项活动的替代度矩阵、90 天三段方案、6 条反模式、5 题自检。

**关键决策**

- 替代度标「本站判断」，并写判断依据（任务是否有明确输入输出、能否自动验证、是否依赖跨团队取舍）。原因：这类数字最容易被当成调研数据引用。
- 不只讲「会替代」，也讲「被替代后谁更值钱」：风险识别只有 19.9% 用 AI，说明判断仍是人。
- 90 天方案每一步都有「交付物」，不是「学习路径」。原因：用户要能拿给主管看。

### 需求 4：测试分类与角色阶梯

**做了什么**：11 个角色：

- 执行层 7：功能（黑盒）、功能（白盒）、接口、自动化、性能、安全、回归与发布保障；
- 建设层 2：自动化工具开发、自动化平台开发；
- AI 层 2：AI 测试开发、AI 全栈。

每个角色：每天交付什么 / AI 接手什么 / 仍然只属于人 / 怎么算干得好 / 对应工具 / 下一站 / 风险。
三级：初级（按用例执行）/ 中级（设计方案并对覆盖负责）/ 高级（定义质量目标、影响架构）。
四象限：用 AI 测 / 测 AI / 与 AI 协作 / 防 AI 风险。

**关键决策**

- 用「角色 × 级别」矩阵，而不是角色清单。原因：同一个「功能测试」在初级和高级的 AI 暴露度完全不同。
- 不写薪资。原因：薪资受城市/行业/公司规模影响太大，没有可靠公开数据源；写了就是编。
- 「AI 与测试的关系」拆成四件事，而不是一个词。原因：大多数讨论把工具、被测对象、同事、风险源混成一团。

### 需求 5：功能与 UI

**做了什么**：UI 从 v4「深色报告台」整体换到 v5「现场手册」：纸感浅色、墨色结构、朱红动作、衬线数字、零圆角、无 emoji、内联 SVG 图标。

**为什么 v4 不行**（自我否定）：

- 全站深色 + 等宽小字，像监控台，不像给人读的产品；
- 所有容器同一个模子（细边框 + 同 padding），没有主次；
- 青色同时承担链接/按钮/数值/选中态，语义塌陷；
- 大量 emoji 做图标，和「数据可信」的定位相反；
- 报告卡继承了墨底的浅色文字令牌，方案名几乎看不见（本轮验收抓出来的真实 bug）。

v5 的规则：**朱红只给动作与结论，墨色承担结构，绿只给通过；数字用衬线，标签用等宽，正文用无衬线；圆角 0。**

## 3. 数据架构

```
人工核过（有来源、有核验日）
  tools.json / plans.json / bundles.json / freebies.json / news.json / roles.json / impact.json
        │
        ├── build.js 校验（字段、引用、日期、夺冠率、模块归属）→ index.html
        │
自动抓取（单独文件、单独标记）
  news-auto.json / _price-snapshots.json / _refresh-report.json
        │
  scripts/refresh.js（RSS + 价格指纹）
        │
  .github/workflows/data-refresh.yml（每周一）
```

四条不变量（build 会拦）：

1. 每个功能页恰好归一个模块；
2. 每个工具 9 个维度分齐全、20 项能力分在 0–5；
3. 每个套餐 8 个维度分齐全、有 region/currency/price；
4. 每条人工新闻有来源 + 对测试的影响；每条免费额度有坑。

---

## 4. 非目标（这一轮明确不做）

- **不做薪资数据**：没有可靠公开源，写了就是编。
- **不做自动改价**：价格解析不可靠，只告警。
- **不做「最佳工具」总冠军**：只做「按你的权重排序」，并保留「换权重排名会变」的夺冠率门禁。
- **不做社区**：只在导航与页脚预留位置，不实现。
- **不做账号体系**：所有个性化存 localStorage，离线可开。

---

## 5. 下一步（按价值排序）

1. **人工核价工作流**：把 `_refresh-report.json` 的「有变化」做成待办清单，逐条核完写回 `verified`。
2. **评测集模板**：给 AI 测试开发角色配一份可复制的 20–50 条评测集骨架（正常/边界/对抗/越权）。
3. **JD 采样**：如果要碰薪资，先做 100 份 JD 的技能词频，不做薪资数字。
4. **采购模式**：按团队规模/合规要求生成一页采购说明（含数据条款、发票、退出路径）。
5. **社区**：等前面有稳定流量再做，否则就是空版块。
