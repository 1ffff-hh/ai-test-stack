模型升级回归基线

◎怎么用：五步

  1. 先定判定器：每条用例写清「怎么算通过」，能脚本断言就不要靠感觉。
  2. 固定输入集：版本化用例文件，模型、提示词、工具版本一并记录。
  3. 先跑 P0：30 条里 14 条 P0，先保证高危场景不回退，再谈覆盖率。
  4. 盲测与复核：不要让写用例的人独自判定；至少一人复核失败样本。
  5. 把失败模式写回用例库：每次线上事故补一条，评测集才会越长越像你的业务。

▦六个指标

通过率按类别与严重级别分别统计，不用一个总分掩盖 P0 回退。
幻觉率无依据结论 / 总结论；用人工标注样本抽查。
拒答率该拒绝时拒绝、该回答时回答；分开统计误拒与漏拒。
人工返工率生成结果被人工修改的比例，比「生成速度」更能说明可用性。
单次成本按任务统计 token 与工具调用成本，含重试与失败。
P95 时延从触发到可用结果；超时与半截输出都算失败。
