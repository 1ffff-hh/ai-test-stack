## 2. 设计原则（v9 收敛为四条）

1. **地板优先**：先保证「读得出来」，再谈风格。任何可见文字 ≥11px；数字一律等宽右对齐。
2. **一套语言**：选中态、强调色、圆角、时长各自只允许一套写法。新增状态必须先证明现有的一套不够。
3. **主题必须完整**：浅色不是深色的反色贴图。任何写死的色值都要问一句「浅色下它还对吗」。
4. **首要决策面离入口最近**：用户来这个站是为了「这 57 档选哪个」，那这张表就不该在第 2876px。

## 3. Token 增量

```css
--fs-floor:11px;      /* 全站文字地板 */
--fs-meta:12px;       /* 次级信息（卡片副标、标签） */
--sel-bg / --sel-line / --sel-fg   /* 唯一的选中态配方，深浅各一套 */
```

颜色规矩不变：`color` 用 `-t` 结尾或 `--act/--ink`；`background/border/gradient` 用不带后缀的主色。
动效规矩不变：只用 `--dur-1/2/3`、`--ease-out/in-out/pop`、`--rise`。
**唯一例外**（已注释说明）：地板规则必须带 `!important`，因为历史层里有 `.tcard .tag`、`#v-plans .nm small` 这类后代选择器，同特异性写在最后一层也打不过。

## 4. 组件规范（v9 新增/收口）

### 4.1 选中态
| 状态 | 规范 |
|---|---|
| 默认 | `--panel` 底 + `--line2` 描边 + `--dim` 字 |
| 选中 | `--sel-bg` 底 + `--sel-line` 描边 + `--sel-fg` 字（青色描边这套） |
| 悬停 | 只动描边，不换底，避免和选中态混淆 |
| 键盘 | `:focus-visible` 2px 外描边，必须和选中态视觉上不同 |

适用：`.preset` `.seg` `.allTab` `.chip`。写死反色（白底黑字）的那套已废除。

### 4.2 数据表
- 表头吸顶（`position:sticky`），排序列可点，状态写进 `aria-sort`，箭头用 `↕ / ↑ / ↓`。
- **同一时刻只允许一列排序**（多列排序在选型场景只会让人怀疑自己在看哪一列）。
- 数值列右对齐 + `font-variant-numeric:tabular-nums`；表头随列一起右对齐。
- 行悬停只加 4.5% 强调色底，不做斑马线（已有细线分隔）。
- 表格上方必须有「这张表有多新」——`.freshBar`：`57 / 57 档在 30 天内核过`，阈值与数据健康页同源（`META.staleAfterDays`）。

### 4.3 功能地图与模块页
- 6 个模块 = 3 列两行，排满不留洞。
- 「不确定从哪开始」= 通栏 CTA 条（`grid-column:1/-1`，图标/文案/动作三列），深色下用主动作色底 + 反色字，浅色下用 `#155e75` 渐变。**不再允许纯白块冒充模块**。

### 4.4 套餐阶梯（次要视图）
- 默认折叠，`aria-expanded` 跟随；展开后是「同厂商档位横排」的梯子。
- ≤760px：厂商名独占一行，档位横向滚动，`→` 不再折行到行首。

## 6. 可访问性

- 对比度：42 视图 × 深浅两主题 = **0 违规**，且审计已补上渐变文字分支。
  自检方法：把 v2.3 那条渐变临时塞回构建产物，审计立刻命中 `1.29:1 / need 3`（`grad:true`），移除后回到 0/0——证明这条规则不是摆设。
- 键盘：排序表头是 `<button>`；阶梯标题 `role="button" tabindex="0" aria-expanded`，Enter/空格都能展开。
- 动效：`prefers-reduced-motion` 下光斑与入场动画静止（沿用 v8 的全量关闭）。
- 打印：表头不再吸顶（`position:static`），新鲜度条转白底，避免 A4 上出现半透明灰块。

## 8. 参照来源

- 同类站实测：llmrates.ai/coding-plans（厂商 × 价格档矩阵、页首列抓取失败）、codingplan.link（首屏即快速对比表）。
- 数据密集表格通行做法：细线分隔不叠斑马线、数值右对齐等宽、吸顶表头、单一列排序 + `aria-sort`、窄屏重排为卡片、控件置于表上方。
- 排版尺度：密集产品界面用 1.2 模数，表格单元 12–14px / 行高 1.35–1.45，微标签 11–12px 大写带字距。
- 主题令牌：语义别名 + 每主题一次映射（Radix 的做法），新站色值走 OKLCH。
- 2026 视觉趋势：减少玻璃拟态与渐变，回到「一个强调色 + 清晰层级」。
